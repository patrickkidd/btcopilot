A person attached this file to a message to a coach who is helping them write down their family's history. The coach cannot see the file; it reads only what you write.

Write out everything the file holds as plain text: every person, with their name, relationship, and dates of birth, marriage, divorce, death or anything else dated; every event, with its date as the file gives it; and every other fact. Keep the file's own words and the person's own words where you can, and keep the order the file has. Give a date exactly as the file says it, and say when the file leaves it unclear. For a photo, write out any writing in it, then say plainly what it shows.

Do not interpret, summarise, judge or add anything the file does not say. Write only the text, with no opening or closing remarks. If you cannot make out part of the file, say which part.
