# SARF definitions: concept pages for coders

One page per SARF code. A coder opens a page while coding to see what the original authors wrote about the code, where to find it, and what has been decided. The pages are food for thought, not a rule book: where a page says RULED, the ruling is quoted; everything else is there to think with.

- **The original authors' words.** Every excerpt is a verbatim quote from Bowen, Kerr, Havstad, Patrick Stinson's writing and rulings, or the IRR coders' meetings, with its source and location. Every quote was checked word for word against its source by a script; the check is repeatable.
- **Status of each code.** Section 1 of every page says, item by item, what is RULED (with the ruling's words), OPEN (and who settles it: the IRR group for coding questions), or UNDECIDED between named options. The table below gives each code's status in five words.
- **Public edition.** This set leaves out excerpts from confidential sources (closed App Seminar meetings, recordings and records of identifiable families, unpublished research material, correspondence) and every path to a source file. A fuller private edition, with those excerpts and links to the source files, exists for authorized coders; ask Patrick Stinson for access.

The previous literature review, which these pages replace, is kept for reference in [archive/](archive/README.md).

## How a page is laid out

Every page opens with a **Coder summary** (the status of the code, the passages that matter most, the main off-theory trap), then:

1. **Status of the code.** Numbered items, each marked RULED, OPEN or UNDECIDED.
2. **What the original authors wrote.** Verbatim quotes, in sub-sections by the question a coder has.
3. **Seminar and IRR discussion.** Excerpts from the IRR coders' meetings, with timestamps. Both sides of each disagreement.
4. **Worked examples.** Cases quoted from the primary source, each followed by the questions a coder faces.
5. **Readings that look right but are off-theory.** The reading, what the sources say instead, and the entry ids.

Within a section, entries are grouped by source: Bowen, Kerr, Havstad, Patrick (writing and rulings), the coders' group (IRR), then any other source.

Each excerpt is one line: an id (a letter for the code and a number; ids never change, and a gap in the numbering is an excerpt kept in the private edition), the quote between curly quotes, the speaker and location key, and one or two sentences for the coder.

## Source keys
