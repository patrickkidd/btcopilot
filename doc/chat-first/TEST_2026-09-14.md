   1970." The line it writes back names both of them, says married, and gives the year.
10. *Type* one more: "Corinne is the daughter of Marcus and Delphine." The line it writes back reads
    "Corinne · daughter of Marcus & Delphine". Nothing you typed named a birth event, and no birth
    event is invented; what is added is who her parents are.

    add a fourth coder to the vote that the next four walks depend on.

act as writing a sentence about something that happened.

most of this on your own; and whether anything makes you want to know who wrote an opinion.

## Walk 9 — the command line

There is no admin web page and no sign-in link for this walk. These run in a terminal. Each prints
a table; adding `--json` to any of them gives the same rows as JSON.

1. *Open* a terminal and *paste* these two lines to set it up once:

```
source /Users/patrick/worktrees/fd362-sandbox/env.sh 8890 /Users/patrick/worktrees/fd362-sandbox/beta3.db
cd /Users/patrick/theapp
```

2. *Type* `uv run flask admin review agenda`. One row per conversation on the agenda, with columns
   for the meeting date, whether coding has started, and whether the vote is open. Right now it is
   the one row for Marcus's move to Arizona.
3. *Type* `uv run flask admin users list`. One row per account, with the email, the name, the roles,
   whether it is active, whether it has a professional licence, and how many records it owns.
   Thirteen rows: yours and the twelve fixture accounts.
4. *Type* `uv run flask admin licences plans`. One row per plan, with its code, its name, the
   amount, the interval and whether it is active. One row: Professional Monthly at 19.99 a month.

What to look for: whether a table is the right shape for the answer, and what you would want to
type next that is not here.
