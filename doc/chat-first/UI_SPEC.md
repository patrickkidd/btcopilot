# UI_SPEC — the canonical approved UI for the chat-first beta

Precedence, highest first: (1) the latest dated owner ruling wins over every earlier ruling and every file; (2) a mockup marked chosen/ratified/converged beats an unmarked option in the same gallery; (3) `UI_STANDARDS.md` (BINDING, 2026-09-02) is the floor for size, type and scrolling and overrides any value in a file that predates it; (4) docs and paraphrases never outrank the owner's own words or the mockup source they describe.
Status values: **RULED** the owner's words exist for it · **MARKED CHOSEN** a mockup or gallery marks it chosen/ratified/converged · **UNMARKED OPTION** present in the corpus with no pick · **SUPERSEDED** replaced, by what is named · **CONFLICT** two sources disagree, named.
This file supersedes prose descriptions in `STATE.md` for every UI question. STATE keeps the project's standing and open work; UI_SPEC keeps the values.
Where sources disagreed, the conflict was resolved here by that precedence rather than left open: the row carries `RESOLVED #n` with the rule and the source, and the "Resolutions" table at the foot carries the decision and what it overrides.
Phone frame is 400px standing in for a ~390pt iPhone, so 1px = 1pt throughout.
