Database scope of the pull request, against master

Every table the branch adds or changes, in one list. Everything else in the database is untouched, including the desktop app's read and write paths. Ids are the shared integer primary key with created_at and updated_at; timestamps are DateTime; JSON columns are JSONB with the SQLite variant. Every reference to a user is user_id. The five review_ tables and the two diagram_ tables are prefixed so their names stay out of the global namespace.
